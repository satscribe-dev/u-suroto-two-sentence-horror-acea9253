# Two-Sentence Horror

Entry for the make.fun bounty
[u-suroto-two-sentence-horror-acea9253](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253):
write the scariest horror story you can in exactly two sentences.

## How it works

`main.py` is a deterministic program (no input, no network, no randomness).
When run, it writes the story to `/output/entry.txt`.

## The story

> The graveyard keeper knows every name on every stone, and he greeted me by mine before I spoke. 'You're early,' he said, 'your stone isn't finished yet.'

Gate check: exactly two sentences, 153 characters, UTF-8 text.
